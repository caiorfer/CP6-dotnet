*Legacy System Refatorado em C#*
Este projeto é uma versão melhorada de um sistema legado desenvolvido em C#. O código foi refatorado para seguir boas práticas de programação orientada a objetos, com foco em legibilidade, reutilização e facilidade de manutenção.


*O sistema inclui:*

Cadastro e gerenciamento de clientes.
Registro e exibição de transações.
Geração de relatórios simples.
Funcionalidades
Clientes

Adicionar cliente.
Remover cliente.
Atualizar nome do cliente.
Exibir todos os clientes.
Transações

Adicionar transação.
Exibir todas as transações.
Relatórios

Gerar relatório com os dados dos clientes.
Utilidades

Cálculo de soma com base em um limite.
Exibir mensagens repetitivas para simular uma interação empresarial.

*Tecnologias Utilizadas*
C#: Linguagem principal utilizada para o desenvolvimento do sistema.
.NET: Plataforma usada para compilar e executar o código.

*Melhorias Aplicadas*
Eliminação de Código Duplicado: Redução de loops repetitivos com uma função reutilizável.
Encapsulamento: Uso de classes e propriedades para proteger os dados.
Padrões de Nomenclatura: Utilização de PascalCase e camelCase para seguir as convenções do C#.
Boas Práticas de Design: Divisão de responsabilidades entre classes e métodos específicos.
Facilidade de Manutenção: Código mais legível e modular, facilitando futuras atualizações.
